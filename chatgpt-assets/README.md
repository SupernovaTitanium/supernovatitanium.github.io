# ChatGPT Assets

Public image assets generated or prepared in ChatGPT for use in ChatGPT, Codex, Markdown, and other clients that can render HTTPS images.

## URL convention

Files stored here are available through GitHub Pages as:

`https://supernovatitanium.github.io/chatgpt-assets/<filename>`

Use descriptive, stable filenames. Prefer PNG for plots and diagrams, and SVG when vector rendering is useful.
